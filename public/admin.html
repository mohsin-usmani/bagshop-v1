Homepage Banners

Upload large photos that appear on the homepage slider. First add a product or category (optional), then choose a photo — the crop tool opens with tabs for Desktop and Mobile, so you can frame each one separately instead of sharing one crop. Click Adjust on an existing banner to reframe it without re-uploading.

Target sizes — Desktop 21:8 (wide) · Mobile 4:3. Choosing a photo opens the crop preview.

Category Images

Upload two photos per category — Left and Right. Each upload opens a cropper with tabs for the three places it's shown (Desktop header, Mobile header, Homepage tile) — frame each one separately so the subject looks right everywhere. On desktop the category page shows both side by side with your logo and the category name between them; on mobile both photos loop one at a time, like the homepage banner. The homepage tile only shows one photo — pick which (Left or Right) once both are uploaded.
